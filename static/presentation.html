O PROJETO

Uma análise que dá para entender e demonstrar.

Em vez de apenas listar alertas, o workspace conecta código, evidências, decisão de gate, revisão por IA e histórico em um fluxo só.

⌕

Encontra padrões

Python usa AST e fluxo de dados básico. JavaScript, TypeScript e Java usam parsers Tree-sitter e regras estruturais.
